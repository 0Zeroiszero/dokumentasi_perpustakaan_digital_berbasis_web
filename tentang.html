Tentang PustakaDigital

Rangkuman README resmi repo 0Zeroiszero/Perpustakaan-berbasis-web — latar, tujuan, fitur, teknologi, struktur folder, dan keputusan teknis — di satu tempat.

Latar Belakang

  • Perkembangan teknologi mendorong layanan perpustakaan beralih ke bentuk digital.
  • Perpustakaan konvensional terbatas oleh jam buka, lokasi, dan jumlah salinan buku cetak, sehingga koleksi tidak selalu bisa diakses kapan saja.
  • Proses peminjaman dan pengembalian buku fisik menambah langkah manual bagi pengguna maupun pengelola.
  • Pengguna membutuhkan bacaan yang cepat dicari dan bisa dilanjutkan kapan saja langsung dari browser.
  • Karena itu PustakaDigital dikembangkan sepenuhnya sebagai perpustakaan digital: koleksinya e-book, tanpa koleksi fisik, peminjaman, maupun pengembalian buku cetak.
  • Sistem menyediakan katalog, pencarian, detail buku, rak pribadi, serta dashboard user dan admin untuk mendukung pengelolaan koleksi.

Tujuan

  • Menyediakan akses koleksi e-book kapan saja, tanpa terikat jam buka atau kunjungan fisik.
  • Mempermudah pengguna menemukan buku melalui pencarian judul/penulis dan filter kategori.
  • Mempermudah pengguna menyimpan buku ke rak pribadi serta melanjutkan bacaan dari halaman terakhir.
  • Mempermudah admin mengelola data buku, penerbit, penulis, dan status akun dalam satu tempat.
  • Menghilangkan proses manual khas perpustakaan fisik, seperti peminjaman, pengembalian, dan denda, karena seluruh koleksinya digital.
  • Menyediakan sistem perpustakaan yang cepat, praktis, dan terstruktur.

Fitur Utama

Beranda (Landing)

Halaman tamu sebagai pintu masuk: tiga sampul koleksi terbaru pada grid 3 kolom dan form registrasi singkat di sampingnya. Pencarian langsung ke catalog.php?q=…, footer muncul setelah scroll, dan user yang sudah login diarahkan langsung ke katalog.

Katalog Buku

Pencarian judul/penulis, filter kategori, dan urutan diproses server-side PHP (form GET + tombol Terapkan). Modal cari dari navbar/topbar, pil genre dari database, hasil dibagikan lewat URL. Kartu buku berisi judul, penulis, kategori, dan dropdown status rak.

Detail Buku & Profil

Sampul, judul, penulis (tautan profil), sinopsis, kategori, penerbit (nama + kota, tautan profil penerbit), tahun, halaman, ISBN, format PDF. Dropdown status langsung menyimpan; Baca Buku membuka reader, dan buku selesai menampilkan Baca Ulang dengan konfirmasi.

Pembaca PDF Inline

PDF.js merender buku langsung di browser (read.php?slug=…). Toolbar: kembali, prev/next, input halaman, Fit Halaman / Fit Lebar. Kanvas mengikuti devicePixelRatio agar tetap tajam di layar HP/Retina. Progres last_page tersimpan otomatis via iframe tanpa reload.

Rak Saya

Tab empat status bacaan server-side; simpan buku dari katalog/detail/profil. Pencarian, filter kategori, status, dan urutan (Terbaru, A–Z, Progres) semuanya server-side. Baca Ulang berkonfirmasi; hapus buku dari rak dengan konfirmasi; empty state mengarah ke katalog.

Akun & Profil

Registrasi terbuka, login email + password (hash Bcrypt), logout yang benar. Profil mandiri untuk ubah nama tampilan, email, dan kata sandi. Akun yang dinonaktifkan admin ditolak saat login dengan pesan jelas.

Dashboard User

Ringkasan aktivitas membaca: jumlah rak, sedang dibaca, selesai dibaca, total koleksi, daftar sedang dibaca, dan aktivitas terbaru — seluruhnya dihitung langsung dari tabel (tanpa data dummy).

Dashboard Admin

Statistik buku/pengguna/penerbit/penulis dan buku terbaru. Kelola Buku dengan upload PDF + sampul GD otomatis, Kelola Pengguna dengan reset password acak sekali-tampil, Kelola Publisher dan Penulis via modal, semuanya pencarian server-side.

Hak Akses

Publik: beranda, katalog, detail, profil penulis/penerbit, login, register. Wajib login: rak, reader, streaming, profil, dashboard user. Wajib admin: dashboard admin dan admin/*. Semua aksi tulis memakai POST + CSRF + redirect + flash.

Keputusan Teknis Mengikat

Disepakati saat perencanaan rombak total (RENCANA-ROMBAK-TOTAL).

  • mysqli prepared statements, bukan PDO

    Tim belum belajar PDO; pola helper lama q()/rows()/row()/scalar()/e() dipertahankan di semua halaman.

  • Tanpa ketergantungan .htaccess

    Tim belum belajar mod_rewrite; slug tetap identitas publik lewat query string (book-detail.php?slug=…). Tidak ada file .htaccess sama sekali.

  • URL migrasi penuh tanpa redirect

    Belum produksi, jadi tidak perlu kompatibilitas URL lama.

  • Nama database optl_pustaka

    Branch optl/rombak-total; dump ramah phpMyAdmin dengan seed data demo.

  • Soft-delete, bukan hapus keras

    Buku/akun dinonaktifkan lewat is_active; hapus keras hanya untuk item rak; master tidak dihapus sama sekali.

  • PDF-saja + PDF.js

    Satu judul satu berkas; format lain dikonversi manual di luar sistem; MODUL VII bukan rujukan.

  • Smoke test menyeluruh

    tests/smoke.php menguji 'semua yang possible', bukan sampel; viewport.py menguji tampilan 320–1366px.

  • Layout public/ sebagai DocumentRoot

    storage/ dan includes/ berada di luar public sehingga tidak punya URL publik.
