Database demo: optl_pustaka

Dump for_demo_optl_pustaka.sql berisi struktur + data demo yang benar-benar dipakai saat demo: 11 akun (termasuk admin & user demo), 11 penulis, 6 penerbit, 10 genre, 11 buku lengkap dengan berkas dan checksum SHA-256, 14 baris rak, dan 11 baris progres. File dump ikut disertakan di folder database/ repo dokumentasi ini.

Koneksi default di includes/config.php: host 127.0.0.1, user root tanpa password (Laragon). Nama file dump persis seperti yang dipakai kelompok: for_demo_optl_pustaka.sql.

VIEW v_books_catalog — jantung katalog

database/for_demo_optl_pustaka.sql (definisi VIEW, dirapikan)

Semua halaman publik cukup SELECT * ke VIEW ini sehingga tidak ada JOIN di PHP (BR-05.2). Definisi asli di dump berbentuk satu baris; berikut versi yang dirapikan.

CREATE OR REPLACE VIEW v_books_catalog AS
SELECT b.book_id, b.title, b.slug, b.description, b.published_year, b.isbn,
       b.storage_path, b.file_size, b.checksum_sha256, b.page_count,
       b.cover_path, b.is_active, b.created_at,
       a.name AS author_name, a.slug AS author_slug, a.country AS author_country, a.bio AS author_bio,
       g.genre_id, g.name AS genre_name,
       p.name AS publisher_name, p.slug AS publisher_slug, p.city AS publisher_city
FROM books  b
JOIN authors    a ON a.author_id    = b.author_id
JOIN genres     g ON g.genre_id     = b.genre_id
JOIN publishers p ON p.publisher_id = b.publisher_id;

Pencarian katalog (public/catalog.php)

public/catalog.php baris 9–20

Pencarian judul/penulis, filter genre, dan urutan diproses server-side dengan prepared statement — nilai user tidak pernah masuk string SQL (BR-05.1, BR-02.4).

SELECT * FROM v_books_catalog WHERE is_active = 1
  AND (title LIKE ? OR author_name LIKE ?)   -- hanya bila ?q= diisi
  AND genre_name = ?                          -- hanya bila ?kategori= diisi
ORDER BY title ASC;                           -- atau book_id DESC (sort=terbaru)

-- daftar pil genre untuk modal/filter
SELECT name FROM genres ORDER BY name;

Rak Saya: JOIN + filter milik sesi (public/my-shelf.php)

public/my-shelf.php baris 20–40

Query rak selalu dibatasi c.user_id = ? (id sesi), digabung VIEW katalog dan LEFT JOIN progres. Filter kategori multi-nilai memakai placeholder dinamis, tetap prepared.

SELECT c.status, c.created_at, v.*, rp.last_page
FROM collections c
JOIN v_books_catalog v ON v.book_id = c.book_id
LEFT JOIN reading_progress rp ON rp.user_id = c.user_id AND rp.book_id = c.book_id
WHERE c.user_id = ?                          -- id dari sesi, bukan input
  AND c.status = ?                           -- hanya bila tab status aktif
  AND (v.title LIKE ? OR v.author_name LIKE ?)
  AND v.genre_name IN (?, ?, ?)              -- placeholder = jumlah kategori terpilih
ORDER BY c.created_at DESC, v.book_id DESC;

Upsert status rak (actions/collection-save.php)

public/actions/collection-save.php baris 17–21

Satu baris per (user, buku) dijaga UNIQUE KEY uq_collections_user_book, sehingga simpan/ubah status cukup satu statement INSERT … ON DUPLICATE KEY UPDATE. status_source selalu 'user' untuk aksi dropdown.

INSERT INTO collections (user_id, book_id, status, status_source)
VALUES (?, ?, ?, 'user') AS baru
ON DUPLICATE KEY UPDATE status = baru.status, status_source = 'user';

-- validasi pendahulu: buku harus aktif
SELECT book_id FROM books WHERE book_id = ? AND is_active = 1;

Progres baca & lifecycle otomatis (actions/progress-save.php)

public/actions/progress-save.php baris 15–54

Auto-save reader: clamp 1..page_count, buat baris system bila belum ada, auto-finished hanya untuk baris ber-source system, lalu upsert last_page.

-- batas halaman
SELECT page_count FROM books WHERE book_id = ? AND is_active = 1;

-- baca status saat ini
SELECT status, status_source FROM collections WHERE user_id = ? AND book_id = ?;

-- buat baris pertama saat belum ada (Baca Buku pertama = Sedang dibaca)
INSERT INTO collections (user_id, book_id, status, status_source)
VALUES (?, ?, 'reading', 'system');

-- auto-selesai HANYA untuk baris milik sistem (BR-03.4)
UPDATE collections SET status = 'finished'
WHERE user_id = ? AND book_id = ? AND status_source = 'system';

-- simpan halaman terakhir (upsert, BR-04.1)
INSERT INTO reading_progress (user_id, book_id, last_page)
VALUES (?, ?, ?) AS baru
ON DUPLICATE KEY UPDATE last_page = baru.last_page;

DDL inti + kunci unik

database/for_demo_optl_pustaka.sql baris 30–341

Tujuh tabel 3NF, semua InnoDB utf8mb4. Kunci unik menjaga aturan bisnis di level database: satu rak per (user, buku), satu progres per (user, buku), slug & ISBN & email tunggal.

CREATE TABLE users (
  user_id int UNSIGNED NOT NULL AUTO_INCREMENT,
  email varchar(100) NOT NULL,
  password_hash varchar(255) NOT NULL,
  display_name varchar(100) NOT NULL,
  role enum('admin','member') NOT NULL DEFAULT 'member',
  is_active tinyint(1) NOT NULL DEFAULT 1,
  created_at timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id), UNIQUE KEY uq_users_email (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE collections (
  collection_id int UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id int UNSIGNED NOT NULL,
  book_id int UNSIGNED NOT NULL,
  status enum('to_read','reading','not_interested','finished') NOT NULL DEFAULT 'to_read',
  status_source enum('system','user') NOT NULL DEFAULT 'system',
  created_at timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (collection_id),
  UNIQUE KEY uq_collections_user_book (user_id, book_id),
  KEY fk_collections_book (book_id),
  CONSTRAINT fk_collections_user FOREIGN KEY (user_id) REFERENCES users (user_id),
  CONSTRAINT fk_collections_book FOREIGN KEY (book_id) REFERENCES books (book_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
-- (reading_progress serupa: UNIQUE uq_progress_user_book (user_id, book_id))
