SPEC Ticket & Pengujian Otomatis

11 ticket SPEC di docs/specs/ — kontrak verifikasi sebelum commit. Dua skrip uji: tests/smoke.php (perilaku) dan tests/viewport.py (tampilan).

SPEC-DB

Fondasi database, berkas, dan helper

CREATE DATABASE optl_pustaka + 7 tabel 3NF + VIEW v_books_catalog + seed, ramah phpMyAdmin (InnoDB, utf8mb4, PK INT UNSIGNED AUTO_INCREMENT). collections & reading_progress UNIQUE(user_id, book_id); FK RESTRICT; books.isbn dipertahankan. Helper: config.php (BASE_URL, url(), asset()), db.php (q/rows/row/scalar/e), auth_guard.php, slug_helper.php (generate_unique_slug), cover_helper.php (sampul GD 600×800), book_helper.php (peta status).

SPEC-01

Beranda & katalog publik

index.php: hero kontrak lama, tepat 2 pintu masuk (Katalog & Rak Saya), cari → catalog.php?q=. catalog.php?q=&kategori=&sort=: modal cari (#modalCari) fokus otomatis, pil genre DB-driven, grid col-6 col-lg-3, kartu + dropdown status 4 nilai POST actions/collection-save.php.

SPEC-02

Detail buku & profil penulis

book-detail.php?slug=: sampul, judul, badge genre, sinopsis, dl 6 informasi, CTA Baca Buku, dropdown status. author.php?slug=: bio, negara, daftar karya. Slug tak dikenal atau buku nonaktif → 404 ramah.

SPEC-03

Autentikasi (login, register, logout, guard)

login.php: password_verify, gagal → ?gagal=1&email=, sukses → ?next= tervalidasi lokal atau dashboard per role, akun nonaktif ditolak dengan pesan jelas, dropdown akun demo. register.php: email unik, password ≥6. logout.php: hancurkan sesi + cookie.

SPEC-04

Profil mandiri

profile.php: tampil + edit display_name, email, kata sandi milik $_SESSION['user_id'] saja (tanpa parameter user_id eksternal). Password baru opsional ≥6; email unik kecuali milik sendiri; flash + redirect.

SPEC-05

Pembaca PDF.js & streaming aman

read.php?slug=: PDF.js CDN, toolbar (kembali, prev/next, input halaman, fit), canvas render, buku nonaktif → 404. stream.php?slug=: 403 tanpa sesi, validasi slug + is_active, readfile() dengan Content-Type/Length, nama berkas hanya {id}.pdf.

SPEC-06

Auto-save last_page (iframe, tanpa AJAX)

Form tersembunyi last_page + csrf bertarget iframe progressFrame → actions/progress-save.php. Handler: INSERT … ON DUPLICATE KEY UPDATE (UNIQUE user+book), clamp 1..page_count, milik sesi sendiri. Tanpa tombol, tanpa reload, tanpa fetch/XHR.

SPEC-07

Rak Saya & dashboard user

my-shelf.php?status=: 4 tab server-side, kartu + CTA per status (Lanjut Baca / Baca Buku / Baca Ulang), toolbar + modal filter UI-only, hapus → collection-delete.php + konfirmasi. collection-save.php: 4 nilai valid, UNIQUE(user,book), milik sesi.

SPEC-08

Master penerbit & penulis (admin)

admin/publishers.php dan admin/authors.php: daftar + tambah/edit via modal (name, city / name, slug otomatis, country, bio), POST sendiri + CSRF + redirect + flash. Tanpa hapus baris master — tombol hapus tidak ada.

SPEC-09

Admin buku, sampul GD, dashboard admin

admin/books.php: daftar + Nonaktifkan/Aktifkan via POST + konfirmasi, tanpa hapus keras. book-form.php: validasi PDF (ekstensi + MIME, ≤50 MB) dan sampul (≤5 MB, getimagesize), tanpa upload saat edit → berkas lama tetap, sampul GD otomatis, slug otomatis. dashboard-admin.php: statistik COUNT + buku terbaru.

SPEC-10

Status pengguna (admin)

admin/users.php: daftar akun + tombol Aktif/Nonaktif POST + konfirmasi; tanpa hapus keras, tanpa edit profil orang lain. Guard: admin tidak dapat menonaktifkan dirinya sendiri; admin aktif terakhir tidak dapat dinonaktifkan.

Menjalankan Uji

tests/smoke.php — uji perilaku

Butuh aplikasi berjalan + DB optl_pustaka. Jalankan via URL …/tests/smoke.php atau php tests/smoke.php. Menguji:

  • Login gagal/sukses/nonaktif, CSRF 419, tolak ?next= eksternal
  • Lifecycle status: system→reading, auto-finished, user tak diubah, reset
  • Pencarian katalog & Rak Saya
  • Upload PDF palsu/valid, sampul, slug, datalist
  • Guard admin & reset password

tests/viewport.py — uji tampilan 320–1366px

Butuh Python + Playwright + aplikasi berjalan. Menguji:

  • Render DPR 2 tetap tajam; kanvas PDF berisi
  • Iframe auto-save terkirim
  • Topbar mobile: subjudul hilang, avatar bulat
  • Dropdown & modal tidak overflow, bisa discroll
  • Judul kartu ter-clamp 2 baris; layout 320–1366px utuh
