Beranda/Alur Bisnis

Business Logic Animasi (BL-01–BL-09)

Tekan Putar untuk melihat alur berjalan langkah demi langkah, atau klik langkahnya langsung. Diagram mermaid di bawah tiap alur menunjukkan keputusan dan cabangnya.

BL-01

Registrasi & Login

Dari form tamu sampai sesi aktif: validasi, hash, regenerasi session, dan arah tujuan sesuai role.

  1. 1Tamu mengisi form registrasi di landing atau halaman register.
  2. 2Server mengeksi (validasi) nama, format email, email duplikat, dan panjang password.
  3. 3Password di-hash (Bcrypt), akun dibuat sebagai member aktif, flash sukses, redirect ke login.
  4. 4Login memverifikasi hash + is_active, regenerasi session id, lalu redirect ke ?next= valid atau dashboard per role.
  5. 5Kegagalan kembali ke login dengan ?gagal=1 atau ?nonaktif=1.
BL-02

Pencarian Katalog

Modal cari di navbar/topbar mengirim form GET; semua filter diproses server-side dan hasilnya dibagikan lewat URL.

  1. 1Pengguna membuka modal cari dari ikon navbar/topbar.
  2. 2Form GET mengirim q, kategori, dan sort.
  3. 3PHP menyusun WHERE prepared: is_active=1, LIKE judul/penulis, genre exact, ORDER BY.
  4. 4Halaman dirender ulang dengan kartu hasil dan badge jumlah.
  5. 5Kombinasi filter dipertahankan pada tautan tab/status dan reset filter.
BL-03

Simpan / Ubah Status

Dropdown status di kartu buku langsung POST ke collection-save.php dan selalu menandai status_source='user'.

  1. 1Pengguna memilih salah satu dari empat status pada dropdown.
  2. 2Form POST ke actions/collection-save.php dengan CSRF, book_id, dan status.
  3. 3Server memvalidasi status & buku aktif.
  4. 4Upsert collections dengan status_source='user'.
  5. 5Flash + redirect ke halaman asal (referer lokal) atau katalog.
BL-04

Membaca & Auto-Selesai

Reader PDF.js menyimpan halaman terakhir otomatis lewat iframe; sistem mengelola status selama user belum memilih sendiri.

  1. 1Pengguna menekan Baca Buku; read.php memuat PDF dari stream.php yang memeriksa sesi.
  2. 2PDF.js merender halaman awal pada resolusi DPR.
  3. 3Setiap render/pindah halaman mengirim last_page + total_pages ke progress-save.php.
  4. 4Jika collections belum ada → buat reading/system; jika system dan halaman terakhir → finished; jika user → status tidak diubah.
  5. 5Progres disimpan, halaman tetap terlihat di posisi terakhir saat dibuka lagi.
BL-05

Baca Ulang

Reset progres yang disengaja: modal konfirmasi dulu, lalu status dikembalikan ke pengelolaan sistem.

  1. 1Pada kartu selesai / detail buku berstatus finished, tombol Baca Ulang memunculkan modal konfirmasi.
  2. 2Batal / Esc / klik luar membatalkan tanpa perubahan.
  3. 3Setuju mengirim POST ke actions/progress-reset.php.
  4. 4Server menetapkan last_page=1, status reading, status_source='system'.
  5. 5Pengguna diarahkan ke reader dengan progres segar.
BL-06

Kelola Buku (Admin)

Tambah/edit buku lewat modal: validasi master, ISBN unik, upload PDF 50 MB, sampul GD otomatis, tanpa hapus keras.

  1. 1Admin membuka modal Tambah/Edit dari daftar.
  2. 2Form mengirim judul, penulis, publisher, genre, tahun, ISBN, sinopsis, PDF, sampul.
  3. 3Server memvalidasi master, ISBN unik, dan berkas.
  4. 4PDF baru masuk nama sementara → INSERT → rename ke {id}.pdf → sampul GD bila kosong.
  5. 5Kegagalan upload menghapus baris/berkas yatim, flash error, modal tetap terbuka.
  6. 6Menonaktifkan buku cukup mengubah is_active, koleksi & progres pengguna tetap utuh.
BL-07

Kelola Pengguna (Admin)

Modal tambah/edit akun dengan guard diri sendiri & admin terakhir, plus reset password acak sekali-tampil.

  1. 1Admin membuka modal Tambah/Edit.
  2. 2Validasi nama, email unik, role, status, dan password awal untuk akun baru.
  3. 3Guard diri sendiri & admin terakhir diterapkan sebelum UPDATE.
  4. 4Tombol Reset Password menghasilkan password acak 12 karakter, menyimpan hash, menampilkan teks sekali.
  5. 5Redirect ke halaman dengan modal terbuka + flash.
BL-08

Rak Saya: Cari, Filter, Urut

Toolbar Rak Saya sepenuhnya server-side: query selalu dibatasi user_id sesi, sort progres dihitung dari persentase turunan.

  1. 1Form toolbar dan modal filter mengirim q, status, sort, kategori[].
  2. 2Query SQL menggabungkan WHERE c.user_id = ? dengan filter prepared.
  3. 3Sort A–Z/terbaru di SQL; sort progres dihitung dari persentase turunan.
  4. 4Tab status mempertahankan filter; empty state menawarkan reset pencarian.
  5. 5Modal filter tetap bisa discroll di layar kecil.
BL-09

Landing & Navigasi

Landing tamu punya dua pintu masuk; begitu login, seluruh aplikasi memakai shell sidebar yang sama.

  1. 1Tamu melihat judul/pencarian, form registrasi, dan 3 buku pada grid 3 kolom.
  2. 2User login yang membuka landing langsung diarahkan ke katalog.
  3. 3Setelah login, katalog/detail/penulis/penerbit/reader/rak/profil/dashboard/admin memakai sidebar yang sama.
  4. 4Footer landing baru muncul setelah scroll; konten utama muat di 1366×768.
