Beranda/Live Coding

Live Coding Asdos — HTML + PHP + sedikit JS (tanpa CSS)

Delapan latihan yang bias muncul saat live coding, ditulis sesederhana mungkin agar fokus ke pemahaman: pola prepared statement, hash, upsert, lifecycle status, dan guard. Semua snippet sengaja tanpa CSS. Setiap kartu punya tab Kode dan Expected Output — output yang mungkin keluar di browser ditampilkan apa adanya di dalam frame. Jalankan lokal: impor dump, lalu php -S localhost:8000 di folder snippet, login pakai akun demo.

Pola helper aplikasi asli

Snippet di bawah menulis mysqli polos supaya terlihat. Aplikasi asli membungkusnya dalam helper di includes/db.php dan includes/auth_guard.php — ini yang perlu kamu sebut saat asdos menanyakan "di mana prepared statement-nya?":

HelperFungsi
q($sql, $params)Prepare + bind (semua param jadi string 's') + execute; mengembalikan mysqli_stmt.
rows($sql, $params)Semua hasil sebagai array asosiatif — dipakai daftar kartu/tabel.
row($sql, $params)Satu baris pertama atau null — dipakai cek ada/tidak (email duplikat, buku aktif).
scalar($sql, $params)Nilai tunggal (COUNT*) — dipakai statistik dashboard dan guard admin terakhir.
e($nilai)htmlspecialchars ENT_QUOTES — semua output HTML wajib lewat ini.
akun()Akun sesi dibaca ulang dari DB tiap request: perubahan role/is_active langsung berlaku.
wajib_login() / wajib_admin()Guard halaman: tamu → login?next=, member → dashboard-user.
cek_csrf()Token sesi vs POST dengan hash_equals; kosong/kedaluwarsa → HTTP 419.
flash($pesan)Pesan sekali-tampil lewat redirect (pola PRG: Post-Redirect-Get).
Snippet 1

Registrasi akun member

Menguji pemahaman validasi sederhana, password_hash, dan prepared statement INSERT.

BR-01.1 · BR-01.3 · BL-01 (versi asli: register.php + helper q()/e() + CSRF + redirect PRG)

registrasi.php
<?php
// registrasi.php — versi live coding: HTML + PHP tanpa CSS, fokus pemahaman.
$koneksi = new mysqli('127.0.0.1', 'root', '', 'optl_pustaka');

$pesan = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nama     = trim($_POST['nama'] ?? '');
    $email    = strtolower(trim($_POST['email'] ?? ''));
    $password = $_POST['password'] ?? '';

    // BR-01.3: email unik + password minimal 6 karakter
    $cek = $koneksi->prepare('SELECT user_id FROM users WHERE email = ?');
    $cek->bind_param('s', $email);
    $cek->execute();

    if ($nama === '' || !filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $pesan = 'Nama wajib diisi dan email harus valid.';
    } elseif ($cek->get_result()->num_rows > 0) {
        $pesan = 'Email sudah terdaftar.';
    } elseif (strlen($password) < 6) {
        $pesan = 'Password minimal 6 karakter.';
    } else {
        // BR-01.1: password polos TIDAK PERNAH disimpan — simpan hash-nya saja
        $hash = password_hash($password, PASSWORD_DEFAULT);
        $simpan = $koneksi->prepare(
            'INSERT INTO users (email, password_hash, display_name, role, is_active)
             VALUES (?, ?, ?, "member", 1)'
        );
        $simpan->bind_param('sss', $email, $hash, $nama);
        $simpan->execute();
        $pesan = 'Akun berhasil dibuat. Silakan login.';
    }
}
?>

Snippet 2

Login dengan password_verify + is_active

Menguji pemahaman verifikasi hash, penolakan akun nonaktif, session_regenerate_id, dan alur ?next=.

BR-01.1 · BR-01.2 · BR-02.2 · BL-01 langkah 4–5 (versi asli: login_user() di auth_guard.php)

login.php
<?php
// login.php — verifikasi hash + is_active + sesi.
session_start();
$koneksi = new mysqli('127.0.0.1', 'root', '', 'optl_pustaka');

$pesan = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $email = strtolower(trim($_POST['email'] ?? ''));
    $stmt = $koneksi->prepare(
        'SELECT user_id, password_hash, is_active, role FROM users WHERE email = ?'
    );
    $stmt->bind_param('s', $email);
    $stmt->execute();
    $user = $stmt->get_result()->fetch_assoc();

    if (!$user || !password_verify($_POST['password'] ?? '', $user['password_hash'])) {
        $pesan = 'Email atau password salah.';          // asli: redirect ?gagal=1
    } elseif ((int) $user['is_active'] === 0) {
        $pesan = 'Akun dinonaktifkan oleh admin.';      // asli: redirect ?nonaktif=1
    } else {
        session_regenerate_id(true);                    // cegah session fixation
        $_SESSION['user_id'] = (int) $user['user_id'];
        $pesan = 'Login sukses. Masuk sebagai ' . $user['role'] . '.';
        // asli: redirect ?next= (tervalidasi lokal) atau dashboard per role
    }
}
?>

Simpan status Rak Saya (dropdown + upsert)

Menguji pemahaman validasi enum, UNIQUE (user, book), dan INSERT … ON DUPLICATE KEY UPDATE.

BR-03.1 · BR-03.5 · BL-03 (versi asli: actions/collection-save.php + CSRF + referer)

rak.php
<?php
// rak.php — dropdown status langsung POST + upsert ke collections.
session_start();               // demo: anggap sudah login sebagai user_id 2 (andi@email.com)
$koneksi = new mysqli('127.0.0.1', 'root', '', 'optl_pustaka');
$user_id = $_SESSION['user_id'] ?? 2;

const STATUS_LABEL = [
    'to_read'       => 'Akan dibaca',
    'reading'       => 'Sedang dibaca',
    'finished'      => 'Telah dibaca',
    'not_interested'=> 'Tidak Tertarik',
];

$pesan = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $book_id = (int) ($_POST['book_id'] ?? 0);
    $status  = $_POST['status'] ?? '';

    // validasi ganda: nilai enum dikenal + buku masih aktif
    $cek = $koneksi->prepare('SELECT book_id FROM books WHERE book_id = ? AND is_active = 1');
    $cek->bind_param('i', $book_id);
    $cek->execute();

    if (!isset(STATUS_LABEL[$status]) || $cek->get_result()->num_rows === 0) {
        $pesan = 'Status atau buku tidak valid.';
    } else {
        // UNIQUE uq_collections_user_book (user_id, book_id) → cukup satu upsert
        $sql = 'INSERT INTO collections (user_id, book_id, status, status_source)
                VALUES (?, ?, ?, "user") AS baru
                ON DUPLICATE KEY UPDATE status = baru.status, status_source = "user"';
        $simpan = $koneksi->prepare($sql);
        $simpan->bind_param('iis', $user_id, $book_id, $status);
        $simpan->execute();
        $pesan = 'Buku disimpan ke Rak Saya: ' . STATUS_LABEL[$status] . '.';
    }
}
?>

progres.html + progres-save.php
<?php
// progres-save.php — clamp + lifecycle + upsert (tanggapan iframe).
session_start();               // user_id 2 (andi@email.com)
$koneksi = new mysqli('127.0.0.1', 'root', '', 'optl_pustaka');
$user_id = $_SESSION['user_id'] ?? 2;
$book_id = (int) ($_POST['book_id'] ?? 0);
$last    = (int) ($_POST['last_page'] ?? 1);

$buku = $koneksi->prepare('SELECT page_count FROM books WHERE book_id = ? AND is_active = 1');
$buku->bind_param('i', $book_id);
$buku->execute();
$buku = $buku->get_result()->fetch_assoc();
if (!$buku) { http_response_code(404); exit('Buku tidak ditemukan.'); }

// BR-04.2: clamp ke 1..page_count (halaman 999 → 285)
$last = max(1, min($last, (int) $buku['page_count']));

// baca status sekarang
$koleksi = $koneksi->prepare('SELECT status, status_source FROM collections WHERE user_id = ? AND book_id = ?');
$koleksi->bind_param('ii', $user_id, $book_id);
$koleksi->execute();
$koleksi = $koleksi->get_result()->fetch_assoc();

if (!$koleksi) {
    // BR-03.3: baca pertama → Sedang dibaca milik SISTEM (bukan langsung selesai)
    $buat = $koneksi->prepare(
        'INSERT INTO collections (user_id, book_id, status, status_source)
         VALUES (?, ?, "reading", "system")'
    );
    $buat->bind_param('ii', $user_id, $book_id);
    $buat->execute();
} elseif ($koleksi['status_source'] === 'system' && $last >= (int) $buku['page_count']) {
    // BR-03.4: baris system otomatis selesai; baris user TIDAK disentuh
    $selesai = $koneksi->prepare(
        'UPDATE collections SET status = "finished"
         WHERE user_id = ? AND book_id = ? AND status_source = "system"'
    );
    $selesai->bind_param('ii', $user_id, $book_id);
    $selesai->execute();
}

// BR-04.1: upsert last_page (UNIQUE user+book)
$q = $koneksi->prepare(
    'INSERT INTO reading_progress (user_id, book_id, last_page)
     VALUES (?, ?, ?) AS baru
     ON DUPLICATE KEY UPDATE last_page = baru.last_page'
);
$q->bind_param('iii', $user_id, $book_id, $last);
$q->execute();

echo 'OK — last_page tersimpan: ' . $last;

Snippet 7

Streaming PDF aman (guard sesi + path)

Menguji pemahaman guard 403, validasi slug, dan pencegahan path traversal dengan realpath.

Matriks akses (stream.php: tamu 403) · BR-05.3 · BR-06.2 (versi asli: public/stream.php)

stream.php
<?php
// stream.php — aliran berkas PDF; 403 tanpa sesi, path tidak bisa dilompati.
session_start();
$koneksi = new mysqli('127.0.0.1', 'root', '', 'optl_pustaka');

if (!isset($_SESSION['user_id'])) {
    http_response_code(403);
    exit('Forbidden: masuk dulu untuk membaca buku ini.');
}

$slug = trim($_GET['slug'] ?? '');
$buku = null;
if (preg_match('/^[a-z0-9-]{1,220}$/', $slug)) {          // slug valid saja
    $q = $koneksi->prepare(
        'SELECT book_id, storage_path FROM v_books_catalog
         WHERE slug = ? AND is_active = 1'
    );
    $q->bind_param('s', $slug);
    $q->execute();
    $buku = $q->get_result()->fetch_assoc();
}
if (!$buku) { http_response_code(404); exit('Buku tidak ditemukan.'); }

$path = realpath(__DIR__ . '/../' . $buku['storage_path']);
$awal = realpath(__DIR__ . '/../storage/ebooks');

// realpath + str_starts_with: ?slug=../../users.sql TIDAK bisa keluar storage/
if ($path === false || $awal === false
    || !str_starts_with($path, $awal . DIRECTORY_SEPARATOR)
    || !is_file($path)) {
    http_response_code(404);
    exit('Berkas tidak ditemukan.');
}

header('Content-Type: application/pdf');
header('Content-Length: ' . filesize($path));
header('Content-Disposition: inline; filename="' . (int) $buku['book_id'] . '.pdf"');
readfile($path);

(HTTP 403 — ditampilkan bila stream.php dibuka tanpa sesi login)

<?php
// logout.php — sesi hanya diakhiri di sini, bukan dengan membuka halaman login.

session_destroy();
echo 'Sesi diakhiri. Kembali ke beranda.';
